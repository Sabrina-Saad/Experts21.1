# Accessible UX & UI design

Designs calm, low-anxiety flows that meet WCAG and suit older users.

**Skill ID:** SK-20 · See `docs/expert-roster.md` for the agents that use this skill.

## When to use

Use this skill when designing or reviewing any screen, flow, or traveler-facing message.

## Procedure

1. Start from the persona's fear and the one thing they need to do on this screen.
2. One primary action per screen; plain language; progress shown (e.g., 'Trip Readiness 4 of 7').
3. Meet WCAG 2.2 AA: contrast, text size up to 200%, tap targets, screen-reader labels, no color-only meaning.
4. Avoid anxiety triggers: fake urgency, countdown timers, dark patterns, surprise fees.
5. Test with first-timers and with users 60+.

## Output

- Flow or wireframe description.
- Accessibility checklist.
- Usability test plan.

## Project context

- Gary & Gloria (50–68) need large type, calm UX and an easy path to a human (`docs/02`).

## Guardrails

- No dark patterns, including in cancellation flows (auto-renewal laws, `docs/05`).
- Follow the team ground rules in `CLAUDE.md` (cite sources, label estimates, escalate safety issues to a human).
