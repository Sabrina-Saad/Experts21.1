# Lifecycle, email & push marketing

Builds onboarding, fare-alert, trial-conversion, renewal and referral journeys.

**Skill ID:** SK-42 · See `docs/expert-roster.md` for the agents that use this skill.

## When to use

Use this skill when designing or improving email, push, or in-app messaging journeys.

## Procedure

1. Map the lifecycle from `docs/07`: inspire → capture → activate → convert → book → in-trip → post-trip.
2. For each stage, define the trigger, message, channel, timing and exit condition.
3. Fare alerts: relevance over volume; let users set frequency.
4. Trial and renewal messages must meet auto-renewal law requirements.
5. Test subject lines and timing; track activation, conversion, retention and referral.

## Output

- Journey map.
- Message drafts.
- Metrics per journey.

## Project context

- Referral offer idea: give 1 month / get 1 month (`docs/07`).

## Guardrails

- Consent and unsubscribe for every channel (CAN-SPAM, TCPA).
- Follow the team ground rules in `CLAUDE.md` (cite sources, label estimates, escalate safety issues to a human).
