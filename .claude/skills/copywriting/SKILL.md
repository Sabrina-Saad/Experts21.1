# Copywriting & content creation

Writes guides, landing pages, scripts, emails and ad copy in the brand voice.

**Skill ID:** SK-38 · See `docs/expert-roster.md` for the agents that use this skill.

## When to use

Use this skill when drafting any marketing or product copy.

## Procedure

1. Name the persona, the channel, the one message and the action you want.
2. Write a headline that names the reader's worry or goal; follow with the specific help.
3. Use short sentences, concrete numbers (with dates), and a single clear call to action.
4. Offer 2–3 headline or hook variants for testing.
5. Run `brand-voice` and `consumer-protection-law` checks before handing off.

## Output

- Draft copy.
- Variants.
- Notes on claims that need substantiation.

## Project context

- Content series ideas in `docs/07` (First Time Abroad, What $1,500 gets you in…, Touristy vs. Local).

## Guardrails

- Disclose affiliate links and sponsorships; substantiate every claim.
- Follow the team ground rules in `CLAUDE.md` (cite sources, label estimates, escalate safety issues to a human).
