# Persona & jobs-to-be-done mapping

Keeps the six personas current and maps each traveler fear to a product feature.

**Skill ID:** SK-06 · See `docs/expert-roster.md` for the agents that use this skill.

## When to use

Use this skill when deciding who a feature, message or piece of content is for, or turning a traveler fear into a product requirement.

## Procedure

1. Name the persona(s) affected: First Passport Fiona, Finally Going Gary & Gloria, Heritage Seeker Hector, Solo Brave Sam, Student Sophia, Off-the-Path Olivia.
2. State the job: 'When I…, I want to…, so I can…'.
3. Name the specific fear or obstacle (getting lost, scams, cost, language, documents, something going wrong).
4. Map it to a feature or content piece and to a success measure.
5. Flag conflicts between personas (e.g., Fiona wants cheap, Gary & Gloria want calm and human help).

## Output

- Persona → job → fear → feature → metric table.
- Notes on conflicts and priorities.

## Project context

- MVP priority: Fiona (volume, virality) + Gary & Gloria (revenue). Others become content verticals (`docs/02`).

## Guardrails

- Don't stereotype; base persona updates on evidence.
- Follow the team ground rules in `CLAUDE.md` (cite sources, label estimates, escalate safety issues to a human).
