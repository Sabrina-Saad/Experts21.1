# Fundraising & investor materials

Prepares the pitch deck, data room and cap table scenarios, and runs investor updates.

**Skill ID:** SK-30 · See `docs/expert-roster.md` for the agents that use this skill.

## When to use

Use this skill when preparing to raise money, talking to investors, or writing an investor update.

## Procedure

1. Build the story: problem (fear stops first-timers) → market (`docs/01`) → product → traction → model (`docs/04`) → competition (`docs/03`) → team → ask.
2. Size the raise from the financial model: 18–24 months runway (seed $1.5M–$3M per `docs/04`).
3. Prepare the data room: model, cap table, legal docs, metrics, research.
4. Model dilution scenarios.
5. Write monthly investor updates: metrics, wins, misses, asks.

## Output

- Deck outline with slide-by-slide content.
- Data room checklist.
- Dilution table.

## Project context

- Use verified figures only in investor material; replace every (verify) figure first.

## Guardrails

- No misleading projections; label forecasts as forecasts. Securities matters need a human lawyer.
- Follow the team ground rules in `CLAUDE.md` (cite sources, label estimates, escalate safety issues to a human).
