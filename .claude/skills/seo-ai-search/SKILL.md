# SEO & AI-search optimization

Handles keyword research, programmatic pages, schema markup and getting cited by AI answer engines.

**Skill ID:** SK-39 · See `docs/expert-roster.md` for the agents that use this skill.

## When to use

Use this skill when planning or optimizing web content for search and AI answers.

## Procedure

1. Find high-intent first-timer queries: 'do I need a visa for [country] as an American', '[city] for first-timers', 'first international flight checklist', 'ETIAS explained'.
2. Plan page templates (programmatic + editorial) with a 'last verified' date on every rules page.
3. Write for citation: clear direct answers near the top, structured facts, FAQ and schema markup.
4. Build internal links into the trip-planning funnel.
5. Track rankings, AI citations, and clicks; refresh decaying pages.

## Output

- Keyword/topic map.
- Page template spec.
- Optimization checklist.

## Project context

- AI search reduces clicks; build brand search and citability (`docs/07`).

## Guardrails

- No thin or copied content; accuracy beats volume.
- Follow the team ground rules in `CLAUDE.md` (cite sources, label estimates, escalate safety issues to a human).
