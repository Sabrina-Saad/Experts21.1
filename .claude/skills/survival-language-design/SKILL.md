# Survival-language curriculum design

Builds trip-specific phrase packs, pronunciation practice and native-speaker review workflows.

**Skill ID:** SK-14 · See `docs/expert-roster.md` for the agents that use this skill.

## When to use

Use this skill when creating or reviewing language content for a destination.

## Procedure

1. Pick the situations a first-timer actually faces: greetings and politeness, airport/immigration, taxi/transit, ordering food, paying, directions, emergencies, allergies, 'I don't speak X — do you speak English?'.
2. Write 30–60 phrases per pack: phrase, phonetic pronunciation for American English speakers, literal meaning, when to use it, politeness level.
3. Add a 2-week practice plan (5–10 minutes a day) and an offline card for the emergency phrases.
4. Get every pack reviewed by a native speaker from the destination (regional usage matters: Mexico vs. Spain Spanish, Brazil vs. Portugal Portuguese).
5. For heritage travelers, add a family-conversation module.

## Output

- Phrase table.
- Practice plan.
- Reviewer sign-off with name/date.

## Project context

- Planned launch languages (`docs/06`): Spanish, French, Italian, Portuguese, German, Japanese, Greek, Tagalog, Vietnamese, Korean.
- Positioning vs. Duolingo: trip-ready in 2 weeks, not a full course (`docs/03`).

## Guardrails

- Machine translation is a first draft only; no pack ships without native review.
- Follow the team ground rules in `CLAUDE.md` (cite sources, label estimates, escalate safety issues to a human).
