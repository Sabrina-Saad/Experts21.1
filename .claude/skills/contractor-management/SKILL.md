# Vendor & contractor management

Sources, contracts, pays and evaluates freelancers, local experts and outside service providers.

**Skill ID:** SK-26 · See `docs/expert-roster.md` for the agents that use this skill.

## When to use

Use this skill when hiring or managing writers, local contributors, native-speaker reviewers, guides, or vendors.

## Procedure

1. Write the brief: deliverable, quality bar, deadline, rate.
2. Source and vet: samples, references, local knowledge, conflicts of interest.
3. Contract: scope, payment, IP assignment, accuracy standards, disclosure rules (`contract-drafting-review`).
4. Pay reliably across borders (e.g., Wise, Stripe Connect) and handle tax forms.
5. Review performance each cycle; keep a bench of backups.

## Output

- Brief template.
- Vendor shortlist with scores.
- Performance review notes.

## Project context

- Rates in `docs/04` and `docs/06`: $150–$500 per guide/pack; one local contributor per launch city; native reviewer per language.

## Guardrails

- Check worker classification and local licensing rules for guides (`docs/05`).
- Follow the team ground rules in `CLAUDE.md` (cite sources, label estimates, escalate safety issues to a human).
