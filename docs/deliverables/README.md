# Deliverables

Lasting outputs from the expert agents go here: analyses, plans, models, briefs, and the engagement decision log.

**File names:** `YYYY-MM-DD-<topic>.md`, for example `2026-11-24-launch-pricing.md`. The decision log is kept in `decision-log.md`.

Each deliverable should:
- name the experts who contributed
- cite its sources
- label estimates and assumptions
